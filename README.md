# Lib.Tokenization (Етап 1 - Група А2)

Ця бібліотека відповідає за токенізацію тексту в проєкті Mini-ChatGPT. Вона забезпечує перетворення рядків на масиви числових ідентифікаторів (ID) та зворотне декодування. Бібліотека підтримує два рівні токенізації: символьний (`CharTokenizer`) та словний (`WordTokenizer`).

## Архітектура та Опис Класів

Проєкт розділений на відповідні шари:

### 1. Domain

* **`ITokenizer`** та **`ITokenizerFactory`**: Основні інтерфейси системи, що гарантують дотримання контрактів.
* **`Vocabulary<T>`**: Узагальнений клас словника. Забезпечує зберігання унікальних токенів, автоматичне розширення масиву та керування ідентифікаторами. Жорстко резервує `ID = 0` для невідомих токенів (`<UNK>`).
* **`WordVocabulary`**: `Vocabulary<string>`, адаптований спеціально для зберігання слів.

### 2. Application

* **`CharTokenizer`**: Реалізує символьну токенізацію. Кожен унікальний символ отримує свій ID.
* **`WordTokenizer`**: Реалізує словну токенізацію. Розбиває текст за пробілами (`Regex.Split`), нормалізує слова (переводить у нижній регістр та видаляє пунктуацію).
* **`TokenizerFactory`**: Фабрика для створення токенізаторів "з нуля" або відновлення з JSON-файлу.

### 3. Infrastructure

* **`TokenizerPayloadSerializer`**: Делегує відновлення токенізатора правильній фабриці на основі `tokenizerKind` та даних `payload` із чекпоінту.

### 4. Root

* **`ContractInfo`**: Зберігає метод `GetContractFingerprint()`, який повертає поточну версію контракту бібліотеки для перевірки сумісності при завантаженні чекпоінтів.

---

## Опис Методів

Бібліотека реалізує наступні ключові методи інтерфейсу `ITokenizer`:

* **`int VocabSize { get; }`**: Повертає поточний розмір словника (включно з токеном `UNK`).
* **`int[] Encode(string text)`**: Приймає текст і повертає масив числових ID. Невідомі токени автоматично отримують `ID = 0`.
* **`string Decode(ReadOnlySpan<int> tokens)`**: Приймає масив числових ID і повертає відновлений текст. Якщо зустрічається `ID = 0`, підставляється базовий токен.
* **`object GetPayloadForCheckpoint()`**: Формує анонімний об'єкт із поточним станом словника (масив `Chars` або `Words`) для подальшої серіалізації в `checkpoint.json`.
* **`BuildFromText(string text)`** *(статичний)*: Аналізує переданий текст (корпус) та формує словник унікальних токенів під час тренування.

## Очікування інтеграції для Етапу 2

Командам з Етапу 2 під час використання нашої бібліотеки слід враховувати наступні правила:

1. **Взаємодія через абстракції:** Усі створення мають відбуватися виключно через інтерфейс `ITokenizerFactory` або статичні методи `BuildFromText`.
2. **Стратегія UNK:** Наша бібліотека гарантує, що метод `Encode` ніколи не викине виняток при зустрічі з невідомим символом чи словом. Усі такі випадки конвертуються в `ID = 0`.
3. **Нормалізація:** Враховуйте, що `WordTokenizer` виконує стиснення тексту з втратами. Він переводить текст у нижній регістр та прибирає пунктуацію. Тому `Decode(Encode("Привіт!"))` поверне `"привіт"`.
4. **Перевірка версій:** Під час завантаження системи використовуйте `ContractInfo.GetContractFingerprint()`, щоб переконатися, що ваш чекпоінт сумісний.
5. **Тестове покриття:** Наша бібліотека покрита NUnit тестами, що включають перевірку round-trip, обробку порожніх рядків та unknown tokens. Ви можете безпечно інтегрувати `ITokenizer`.
